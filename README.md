# CapstoneFlow

CapstoneFlow is a SENG 701 capstone project focused on connecting project requirements, weekly status reports, reviewer feedback, evidence links, and checkpoint readiness in one workflow.

## Current status

This repository contains proposal-stage materials for the Fall 2026 project. The project direction is selected, while client/sponsor approval and instructor feedback are still pending.

## Repository structure

- `docs/` — proposal summary, development plan, and requirements
- `prototype/` — interactive browser prototype using fictional demonstration data
- `app/` — planned Flask application source
- `tests/` — planned unit, integration, authorization, readiness, and acceptance tests
- `releases/` — checkpoint artifacts for Alpha, Beta, and Final

## Interactive prototype

Open `prototype/index.html` in a browser. It demonstrates:

1. Sign in and role selection
2. Project dashboard and checkpoint readiness
3. Requirement filtering and status tracking
4. Weekly status reporting
5. Reviewer feedback
6. Evidence links

The prototype uses fictional demonstration data and does not implement production authentication or persistence.

## Baseline scope

The proposal defines 12 baseline user stories (R1–R12). Core areas are project setup, requirements planning, weekly reporting, reviewer feedback, evidence traceability, readiness rules, and protected access.
